# Лабораторная работа №8. Проектирование и реализация базы данных

Подготовка PostgreSQL 16+. Работа выполняется в существующей ветке `isit-8`; готовой SQL-заготовки в ней нет. Пример tasks/projects/users будет реализован по методичке, проверен и сохранён отдельным коммитом, затем перенесён на предметную область ЛР1 и ресурсы ЛР7.

## Карточка проектируемой базы

| Элемент | Система учёта заявок |
| --- | --- |
| Основная сущность | tickets — заявки |
| Связанная 1:N | categories — категории |
| Третья сущность | staff — сотрудники поддержки |
| Связь N:M | tickets — tags через ticket_tags |
| Связь 1:1 | staff — staff_profiles |
| Дополнительная сущность | comments — комментарии заявок |
| Поля и проверки | title от 3 символов; description; status new/in_progress/done; priority low/medium/high/critical; category_id; необязательные assignee_id и due_date |

В основной части используются SQL и PostgreSQL; подключение PHP к БД остаётся следующей лабораторной работой.
