# Лабораторная работа №5: Реализация клиентской логики

---

## 1. Цель работы
Приобрести практические навыки реализации клиентской логики современных веб-приложений: обработки пользовательских событий, программного изменения содержимого страницы через DOM API без перезагрузки и асинхронного взаимодействия с сервером по протоколу HTTP (Fetch API).

## 3. Описание реализованной клиентской логики

### 3.1. Обработка пользовательских событий
- В обработчике отправки формы `onFormSubmit` вызывается `event.preventDefault()` для предотвращения перезагрузки страницы.
- Реализована валидация введенного названия: если длина строки менее 3 символов, выводится сообщение об ошибке красным цветом и выполнение прерывается.
- Подключены слушатели событий:
  - `submit` на форме;
  - `click` на кнопке «Загрузить с сервера» и кнопках управления строками;
  - `change` на выпадающем списке фильтрации по статусу;
  - `input` на поле поиска по названию.

### 3.2. Манипуляции с DOM
- Динамическое создание строк таблицы с использованием метода `document.createElement()`.
- Безопасная вставка пользовательского ввода через свойство `.textContent` (предотвращение XSS-уязвимостей).
- Переключение состояния выполнения задачи через `element.classList.toggle('done')`.
- Удаление узлов DOM методом `element.remove()` с запросом подтверждения через `confirm()`.
- Динамический пересчёт общего числа записей в счётчике.

### 3.3. Асинхронные запросы (Fetch API) и состояния интерфейса
Реализована обработка 4 состояний экрана:
1. **Загрузка (loading):** отображается служебное сообщение, кнопка загрузки блокируется (`disabled = true`).
2. **Данные получены (success):** таблица наполняется строками, информационный блок скрывается.
3. **Данных нет (empty):** выводится уведомление «Задачи не найдены. Измените фильтр или текст поиска».
4. **Ошибка (error):** в случае ошибки сети или статуса 500 выводится сообщение об ошибке красным цветом.

## 4. Спецификация API (Домашняя доработка)

| Метод | URL-адрес | Тело запроса | Ответ | Коды ответов | Описание |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `GET` | `/api/tasks` | — | Массив объектов `Task[]` | `200 OK`, `500 Error` | Получение списка задач с фильтрацией |
| `GET` | `/api/tasks/:id` | — | Объект `Task` | `200 OK`, `404 Not Found` | Получение задачи по ID |
| `POST` | `/api/tasks` | JSON: `{ title, priority, status }` | Созданный объект `Task` | `201 Created`, `422 Unprocessable` | Создание новой задачи |
| `DELETE` | `/api/tasks/:id` | — | `{ success: true }` | `200 OK`, `404 Not Found` | Удаление задачи |
