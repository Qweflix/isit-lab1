# Предметная область и ресурсы

Источник: «Система учёта заявок пользователей», вариант 6, ЛР1. Основная и связанная сущности сохранены из выполненной ЛР6 в ветке `isit-lab6`.

| Что определить | Значение |
| --- | --- |
| Основная сущность | Заявка, `ticket` / `tickets` |
| Связанная сущность | Категория обращения, `category` / `categories` |
| Третья сущность | Сотрудник поддержки, `staff` (собирательное имя коллекции) |
| Поля заявки: 6 с учётом ID | `id`, `category_id`, `title`, `description`, `status`, `priority` |
| Статусы | `new`, `in_progress`, `done` |
| Приоритеты | `low`, `medium`, `high`, `critical` |
| Поля категории | `id`, `title`, `description` |
| Поля сотрудника: 4 с учётом ID | `id`, `name`, `email`, `role` |
| Связь | `tickets.category_id` → `categories.id` |
| Начальные данные | 6 заявок, 3 категории, 3 сотрудника; все ID числовые |

Категория содержит заявки, её нельзя удалить до удаления или переноса связанных заявок (409). Сотрудники представлены отдельным справочником; назначение исполнителя не добавлялось в заявку, чтобы сохранить структуру из ЛР6 и ограничение числа полей. Поле `role` — должность сотрудника, не система авторизации.

| Ресурс | Адреса | Методы | Назначение | Формат |
| --- | --- | --- | --- | --- |
| Заявки | `/api/tickets`, `/api/tickets/{id}` | GET, POST, PUT, PATCH, DELETE | Список, просмотр, создание, изменение, удаление; фильтры status/category_id и поиск q | JSON |
| Категории | `/api/categories`, `/api/categories/{id}`, `/api/categories/{id}/tickets` | GET, POST, PUT, PATCH, DELETE | CRUD категорий и вложенный список заявок | JSON |
| Сотрудники | `/api/staff`, `/api/staff/{id}` | GET, POST, PUT, PATCH, DELETE | CRUD сотрудников поддержки | JSON |

До переноса реализованы задачи, проекты и участники: [таблица примера](resources-baseline.md), [82 проверки](baseline-testing.md). Контрольная точка до переноса — коммит `de0f3ba`. После него изменены контроллеры API, имена моделей, файлы JSON, поля clean/validate, маршруты и HTML-сайт. Общие `Router`, `helpers.php`, `JsonRepository` при переносе не изменялись.

Старые `/api/tasks`, `/api/projects`, `/api/users` возвращают 404. Поиск `q` добавлен после переноса; это дополнительная возможность из раздела повышенной сложности, выбранная для домашней доработки.
