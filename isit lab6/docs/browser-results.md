# Проверка в Chromium

Скриншоты сделаны Playwright в Chromium с настоящего встроенного сервера PHP. Использована временная копия приложения; исходные JSON не менялись.

| Адрес / действие | HTTP-код | Скриншот |
| --- | --- | --- |
| `/` | 200 | `01-home.png` |
| `/tickets` | 200 | `02-tickets.png` |
| `/tickets/3` | 200 | `03-ticket.png` |
| `/categories/2` | 200 | `06-category.png` |
| `/tickets/create` | 200 | `07-create.png` |
| `/nonexistent` | 404 | `05-404.png` |
| `POST /tickets`, пустое название | 422 | `04-create-errors.png` |

Корректная форма отправлена браузером: переход на `/tickets`, ответ 200 после 302; созданная запись найдена в списке и JSON (7 записей в тестовой копии). Ошибок JavaScript нет. Сетевые запросы и цепочка перенаправления записаны в [browser.har](browser.har).

[08-http.png](../images/08-http.png) показывает сохранённый вывод настоящих команд curl из [http-headers.txt](http-headers.txt), открытый как текст в браузере. Это скриншот HTTP-проверок, а не вкладки DevTools Network. Вкладку Network для демонстрации преподавателю можно открыть вручную (F12).
