## Границы проверки

Фактически запущены PHP 8.4.24, проверка синтаксиса 22 файлов, 24 HTTP-сценария до переноса и 30 после него, Chromium/Playwright и curl. Не запускались PHP 8.2/8.3, Firefox/Safari и принудительная ошибка хранилища для ответа 500. Вместо снимка DevTools Network сохранены реальные HTTP-заголовки и HAR браузера; это явно подписано в отчёте.

Задания «Повышенная сложность (по желанию)» не реализованы. Основной вариант сохраняет ответ 404 для неподдерживаемого метода, не добавляет удаление, пагинацию, сессии и REST API. Таблица HTML-маршрутов приведена в README; проект готов для последующего проектирования API, но не выдаёт HTML-маршруты за REST API.
