# Лабораторная работа №6. Разработка серверной части приложения

---

## 1. Цель работы
Изучить основы разработки серверной части веб-приложений на языке PHP, организовать модульную архитектуру MVC (Model-View-Controller), реализовать механизм диспетчеризации и маршрутизации HTTP-запросов (Front Controller), написать контроллеры для обработки запросов и реализовать хранение данных с валидацией.

---

## 2. Предметная область (Шаг 5)
В качестве предметной области выбрана **«Система управления командными задачами»**:
* **Основная сущность:** Задачи (`tasks`). Поля: `id`, `member_id`, `title`, `status`, `priority`, `due_date`.
* **Связанная сущность:** Участники команды (`members`). Поля: `id`, `name`, `role`, `email`.
* **Поле фильтрации:** `status` со значениями `new`, `in_progress`, `done`.

---

## 3. Архитектура и структура проекта
Проект построен по принципу единой точки входа (`Front Controller`):
* `public/` — общедоступный каталог веб-сервера. Содержит точку входа `index.php` и CSS-стили.
* `app/Core/` — маршрутизатор `Router.php`, анализирующий URI и HTTP-метод.
* `app/Controllers/` — классы-контроллеры (`HomeController`, `TaskController`, `MemberController`).
* `app/Models/` — репозитории для чтения и записи JSON (`TaskRepository`, `MemberRepository`).
* `app/Views/` — шаблоны страниц и компонентов (шапка, подвал, формы, ошибки).
* `routes/web.php` — таблица зарегистрированных маршрутов приложения.
* `storage/` — файлы хранения данных в формате JSON (`tasks.json`, `members.json`).

---

## 4. Маршрутизация и обработка HTTP-запросов
В классе `Router` реализована регистрация маршрутов с методами `GET` и `POST`, поддержка динамических именованных параметров (например, `/tasks/{id}`) с использованием регулярных выражений, а также корректный перехват несуществующих страниц с возвратом HTTP-кода 404.

### Таблица маршрутов
| Метод | URL | Контроллер и метод | Назначение |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | `HomeController::index` | Главная панель со статистикой |
| `GET` | `/tasks` | `TaskController::index` | Список задач с фильтрацией |
| `GET` | `/tasks/create` | `TaskController::create` | Форма создания задачи |
| `POST` | `/tasks` | `TaskController::store` | Обработка создания задачи |
| `GET` | `/tasks/{id}` | `TaskController::show` | Просмотр отдельной задачи |
| `GET` | `/members` | `MemberController::index` | Список участников команды |
| `GET` | `/members/{id}` | `MemberController::show` | Карточка участника с его задачами |

## 6. Вывод
В ходе лабораторной работы освоено построение легковесного MVC-приложения на чистом PHP без применения сторонних библиотек. Реализован шаблон Front Controller, написан собственный маршрутизатор с поддержкой URL-параметров, обеспечена изоляция слоя данных через репозитории, настроена защита от XSS через экранирование вывода `e()` и организован цикл обработки POST-запросов с редиректом (PRG — Post/Redirect/Get).
